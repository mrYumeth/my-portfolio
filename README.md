# Yumeth Thenuwara — Personal Portfolio

A modern, responsive portfolio website for **Yumeth Thenuwara**, a graduate Software Engineer and developer. The site presents my technical skills, software projects, professional experience, education and contact information through an accessible, mobile-friendly interface.

## Live Website

**Portfolio:** [https://www.yumeth.me](https://www.yumeth.me)

The website is hosted using **GitHub Pages** and connected to a custom Namecheap domain.

## Main Features

- Responsive desktop, tablet and mobile layouts
- Light and dark colour modes
- Sticky desktop navigation and mobile drawer menu
- Animated section reveals using Framer Motion
- Reduced-motion accessibility support
- Modern About, Skills, Projects, Experience, Education and Contact sections
- Project screenshots, technology tags and status labels
- GitHub source-code and live-demo links
- Email, LinkedIn, GitHub and WhatsApp contact options
- Floating WhatsApp contact button
- Custom domain support through GitHub Pages

## Featured Projects

- **CarNeeds.lk** — AI-powered vehicle marketplace for Sri Lanka
- **FieldSync** — Offline-first mobile data collection and cloud synchronisation system
- **StarEvents** — Full-stack event ticketing and management platform
- **Urban Hotels** — Full-stack hotel reservation and management system
- **Luma Music Player** — Offline Flutter music player for Windows
- **Banking Bot** — Java-based banking chatbot using Natural Language Processing concepts

## Local Development

```bash
git clone https://github.com/mrYumeth/my-portfolio.git
cd my-portfolio
npm install
npm run dev
```

The application will normally run at:

```text
http://localhost:5173
```

## Available Scripts

| Command | Purpose |
|---|---|
| `npm run dev` | Start the Vite development server |
| `npm run build` | Create an optimised production build |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint checks |
| `npm run deploy` | Publish the production build to `gh-pages` |

## Deployment

```bash
npm run build
npm run deploy
```

The custom domain is preserved through `public/CNAME`:

```text
www.yumeth.me
```
